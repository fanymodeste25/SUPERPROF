## 👨‍🎓 Parcours Élève

### Parcours 1: Première Visite → Premier Cours Réservé

#### Phase 1: Découverte (0-2 minutes)

**Objectif**: Comprendre la proposition de valeur

```
1. Arrivée sur la page d'accueil
   │
   ├─> Visualisation du hero banner
   │   "Trouvez le professeur idéal parmi 2,847 experts"
   │
   ├─> Barre de recherche proéminente
   │   [Quelle matière?] [Où?] [🔍 Rechercher]
   │
   └─> Sections rassurantes
       • "Comment ça marche" (3 étapes simples)
       • Témoignages d'élèves
       • Top professeurs
       • Catégories populaires
```

**Points de sortie**:
- 🚪 Quitte le site (bounce) → Retargeting ads
- ✅ Continue → Phase 2

#### Phase 2: Recherche (2-5 minutes)

**Objectif**: Trouver des professeurs potentiels

```
2. Recherche de professeurs
   │
   ├─> Saisie des critères
   │   Matière: "Mathématiques"
   │   Lieu: "Paris 15ème"
   │   Niveau: "Lycée"
   │
   ├─> Affichage des résultats (127 professeurs)
   │   │
   │   ├─> Tri par: Pertinence / Prix / Note
   │   │
   │   └─> Filtres avancés
   │       • Prix: 20-50€/h
   │       • Mode: En ligne / À domicile
   │       • Premier cours gratuit
   │       • Note min: 4⭐
   │
   └─> Parcours de la liste
       • Vue carte / Vue liste
       • Aperçu rapide des profils
       • Ajout aux favoris ❤️
```

**Actions possibles**:
- 👀 Clic sur un profil → Phase 3
- 💬 Message direct → Phase 3 (raccourci)
- ❤️ Ajout aux favoris → Continue à chercher

#### Phase 3: Évaluation (5-10 minutes)

**Objectif**: Évaluer la qualité du professeur

   │   • ✅ Identité vérifiée
   │
   ├─> Avis (lecture des 5 derniers)
   │   ⭐⭐⭐⭐⭐ "Excellente pédagogue..."
   │   ⭐⭐⭐⭐⭐ "Très patiente et claire..."

## 📊 Métriques de Succès par Parcours

### Parcours Élève
- **Taux de conversion inscription**: 15-20%
- **Temps moyen avant 1ère réservation**: 2-3 jours
- **Taux de complétion 1er cours**: 85%
- **Taux de réservation 2e cours**: 60%

### Parcours Professeur
- **Taux d'approbation**: 70%
- **Délai d'approbation**: 24-48h
- **Temps avant 1ère demande**: 3-7 jours
- **Taux de conversion demande**: 80%

### Points de Friction à Optimiser
1. Inscription trop longue → Réduire à 2 min
2. Attente approbation → Auto-approval pour profils qualité
3. Recherche peu de résultats → Élargir rayon auto
4. Abandon au paiement → Simplifier checkout

## 🎯 Optimisations Recommandées

### Pour Élèves
1. **Onboarding progressif**: Demander le minimum au départ
2. **Social proof**: Avis et témoignages visibles partout
3. **Urgency**: "3 élèves regardent ce profil en ce moment"
4. **Trust badges**: Paiement sécurisé, professeurs vérifiés

### Pour Professeurs
1. **Gamification**: Badges, niveaux, défis
2. **Support proactif**: Chat pendant l'onboarding
3. **Community**: Forum, événements, ressources
4. **Outils pédagogiques**: Templates, exercices, conseils

### Pour Admins
1. **Automatisation**: Validation automatique si score > 90
2. **Priorités**: Queue intelligente (urgence, qualité)
3. **Analytics**: Dashboard temps réel
4. **Alerts**: Notifications pour cas critiques
